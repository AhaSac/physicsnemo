# 检索范围、覆盖与限制

检索截止 2026-09-28。用户先要求 Luminary、PhysicsNeMo 从发布以来的论文，随后扩展到其他 AI CFD 企业。本次优先完整枚举有明确边界的官方目录，再扩展企业、核心方法和数据集。没有把任意含有 “luminary” 的天文学／照明文献纳入。

## 检索与筛选

主要查询组合包括公司名 + CFD / physics AI / paper / publications，精确论文题名 + PDF / arXiv，以及 PhysicsNeMo / Modulus / SimNet + data / aerodynamics。对 Luminary 另检索 `"Luminary Cloud" "2023" "paper" CFD`、2024、2026 AIAA 及 arXiv；剔除同名无关结果。员工入职前的所有论文没有机械地算作公司论文；仅补入有明确公司署名且涉及流场处理的相关工作。

初始清单在 `additional_papers.json`，后续补充在 `late_papers.json`。PN ID 对应官方目录，EX ID 对应补充记录。同一 arXiv 工作保留一条，下载时获取可用版本；不为会议与预印本重复计数。部分期刊目录年份与预印本首发年份不同，保留原始目录年份并另存源日期。

扩展企业覆盖具有代表性，不声称穷尽世界上所有 AI CFD 企业及论文。公司博客、数据卡、技术报告、会议摘要、同行评审论文和学位论文保留类型差别。Luminary 的 SHIFT-Wing、Pump 等卡片写明数据集论文正在准备中，本次未虚构论文记录。SHIFT-Truck 的 ASME 页面作为会议摘要资料保存。

## 下载和验证

下载仅写入本目录。arXiv 请求串行并设置间隔；出版社公开文件有限并发。PDF 检查文件头、`pdftotext` 解析、页数和 SHA-256；索引生成时再逐份计算哈希并检查题名词在前 3 页的覆盖。命中低分的条目另存 `metadata/title_review_flags.json`，人工核对是否为不同版本、扫描件或错误文件。

HTTP 错误、超时、权限要求和无公开链接不能相互替代。下载失败不会生成虚假 PDF，缺失记录保留来源。部分 `sources/` HTML 是失败响应证据，成功资料入口见 `资料来源索引.md`；原始 Hugging Face README 的权限错误与可公开阅读的数据卡网页区分保存。

`metadata/pdf_integrity.json` 是 PDF 校验记录；请求日志记录公开 URL、响应码和网络错误。`manifest.json` 含完整元数据，CSV 便于筛选，BibTeX 便于导入。论文全文阅读重点放在 CFD 数据生成／处理相关核心条目；非 CFD 官方目录条目完成书目与文件校验，不宣称全部精读。
