A Practitioner's Reality Check: Classical CFD vs. Neural Surrogates on a Single Consumer GPU

Authors/Creators

  • Fujiwara, Hiroki

Description

Abstract—Recent large-scale benchmarking efforts (e.g., REALM [1]) have shown that neural surrogate models for multiphysics flows often report strong nominal accuracy metrics while missing key transient structures and integral quantities. This paper asks a narrower, practitioner-oriented question: on the kind of small, well-posed problem that a working CFD engineer encounters daily, how does a classical linear reduced-order model (POD-Galerkin, Dynamic Mode Decomposition) compare to a modern neural surrogate (NVIDIA PhysicsNeMo), when both are run end-to-end on a single consumer workstation? We report results from three self-contained experiments — parametric interpolation via POD-ROM vs. a fully-connected neural surrogate, transient analysis via DMD, and interface prediction via a CNN applied to a two-phase (VOF) flow — all executed on a single RTX 4090 GPU. Under conditions favorable to linear ROM (smooth, low-dimensional, single-geometry problems), classical ROM methods remain substantially more accurate and equally fast; neural methods degrade further under autoregressive rollout on sharp-interface (multiphase) data. We report these results with their limitations stated explicitly and position this work as an early, practitioner-level data point rather than a comprehensive benchmark, drawing on nine years of industrial CFD experience (Siemens STAR-CD/STAR-CCM+).

Index Terms—CFD, neural surrogates, reduced-order modeling, proper orthogonal decomposition, dynamic mode decomposition, benchmarking, HPC on consumer hardware
